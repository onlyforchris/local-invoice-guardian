# 使用说明

## 目录与查重关系

- **本次新发票文件夹**：员工本次提交、尚待核对的发票。
- **历史已使用发票库**：已经报销或入账的历史发票，可填写多个文件夹并用分号分隔。
- **查重结论**：系统把本次新票与历史库按文件内容、发票号码、金额等信息比较。
- **使用状态**：人工台账标记，不等于查重结论。

“与历史已用票重复”表示新票在历史库中找到了相同票据；“未发现相同票据”表示当前配置的历史库中未找到，不代表税务验真通过。

## 基本使用

1. 填写本次新发票文件夹。
2. 填写历史已使用发票库。
3. 点击“开始查重”。
4. 优先检查“与历史重复”和“需人工复核”的记录。
5. 财务确认后，可改分类、标记已使用，或导出 CSV 明细与 xlsx 分类汇总表。

程序只读取配置的发票目录；只有点击“复制归档”时才会向指定归档目录复制文件，不删除原文件。

## 分类维护

点击右上角“维护分类”，可以新增、改名或删除一级分类，并维护对应二级关键词。票面同时命中多个关键词时，更具体的长词优先；单张发票也可以在结果表中人工改类。

默认规则中，“零食、食品”归入“人事福利”；“餐饮招待、宴请、茶叶、礼品”归入“业务招待费”。最终分类应由财务复核。

## 配置智谱 API Key（贴进去就能用）

文本型 PDF 通常不需要 API Key。图片、扫描 PDF 或文本层损坏的 PDF 需要 AI 识别。

1. 打开[智谱平台 Key 管理页](https://open.bigmodel.cn/usercenter/apikeys)，用手机号注册并登录。
2. 点击「创建 API Key」，名称随意（比如"发票管家"），创建后点「复制」。
3. 回到发票管家，在"识别方式"区点「配置方法」，把 Key 粘贴进弹窗的输入框，点「保存并检测」。看到"连接正常"即完成，**不需要重启、不需要命令行**。

Key 保存在本机 Windows 用户设置中，不会写入项目文件。旧版本用命令行配置过的 Key 继续有效，无需重新配置。程序也兼容 `ZAI_API_KEY`。不要把 Key 写入源码、配置文件、Issue 或截图；泄露后应立即到智谱平台删除并重新创建。

## 在线升级

双击 `升级发票管家.bat` 会安装 GitHub 最新正式 Release、补齐新增依赖并重启；本地配置、台账和虚拟环境不会被覆盖。

## 数据与边界

- 配置和台账保存在本机 `config.json`、`invoice_ledger.json`，二者已被 Git 忽略。
- 开启 AI OCR 后，图片或 PDF 页面会发送到智谱接口；敏感票据应先取得授权。
- 本工具不登录电子税务局，不执行勾选、入账、抵扣或申报，也不替代官方发票验真。
- 首次扫描或解析规则升级后需要重新 OCR，耗时会比后续增量扫描长。

## 常见问题

### 为什么分类正确，但号码或金额未识别？

分类可能只命中了“通行费”等少量文字，而发票数字所在的 PDF 文本层已经损坏。启用 AI OCR 后重新扫描；仍缺失的字段会明确显示“需复核”。

### 为什么以前显示重复，现在不显示？

查重只针对当前填写且实际存在的历史库文件。历史文件被移走、重命名到未配置目录或删除后，下一次扫描不会继续把它当作历史重复依据。

### 如何提交问题？

请提供软件版本、脱敏后的现象和可复现步骤。不要提交真实发票、完整税号、API Key、本机用户名或公司内部目录。
