智谱 AI 配置

API Key 被删除、无效、权限不足、触发限流或服务不可用时，AI 识别会停止；文字 PDF 仍可切换为本地识别继续处理。

在 智谱开放平台 创建 Key，然后在 PowerShell 执行：

[Environment]::SetEnvironmentVariable('ZHIPUAI_API_KEY','粘贴你的 API Key','User')

Key 只保存在 Windows 用户环境变量中，不会写入项目或上传到 GitHub。
