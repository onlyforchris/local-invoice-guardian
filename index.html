智谱 AI 配置

配置很简单，只需 3 步，全程点点鼠标，不用敲任何命令：

  1. 打开智谱官网 open.bigmodel.cn（点此打开），用手机号注册并登录，和注册普通网站一样；
  2. 点页面上的「创建 API Key」，名字随便填（比如"发票管家"），创建成功后点「复制」；
  3. 把复制来的一长串钥匙粘贴到下面的框里，点「保存并检测」，看到绿色"连接正常"就完成了。

这串钥匙只保存在你自己的电脑里，不会上传，也不会写进项目文件。只有图片和扫描件会发给智谱做识别，文字版 PDF 不出你的电脑。

提示"Key 无效"多半是没复制完整：回网页重新点「复制」，再粘贴一次即可。换电脑或重装系统后，重复上面 3 步就行。
